4. Tái hiện lỗi hỏng tra cứu dữ liệu (Hash Corruption & Ghost Entries) khi biến đổi trường của Mutable Key sau khi đã đưa vào `HashMap`.
5. Đề xuất chuẩn thiết kế bất biến (`final class`, `final fields`) cho các Key định danh trong hệ thống backend.

## 2. Bốn biến thể chìa khóa (Key Variants)

| Biến thể | Class | Đặc điểm thiết kế | Hiện tượng trên HashMap / HashSet |
|---|---|---|---|
| **A (Identity)** | `IdentityPlayerKey` | Không override `equals()` & `hashCode()`. Kế thừa mặc định từ `Object.class`. | Hai object riêng biệt có cùng `playerId` và `serverId` sẽ **fail lookup** (`map.get` trả về `null`). HashSet không deduplicate được (size = 2). |
| **B (Equals Only)** | `EqualsOnlyPlayerKey` | Override `equals()`, **CỐ Ý KHÔNG** override `hashCode()`. | Vi phạm nghiêm trọng hợp đồng: khi hash code khác nhau, HashMap tìm sai bucket nên `map.get` trả về `null` dù `equals()` là `true`. |
| **C (Value Key)** | `ValuePlayerKey` | `final class`, field bất biến, `equals()` & `hashCode()` chuẩn mực bằng cả 2 field. | Thỏa mãn đầy đủ tính chất phản xạ, đối xứng, bắc cầu, an toàn null/type. `map.get(key2)` thành công 100%, ghi đè đúng, HashSet deduplicate chính xác (size = 1). |
| **D (Mutable Key)** | `MutablePlayerKey` | Có field `serverId` thay đổi được sau khi khởi tạo. | **Nguy cơ rò rỉ bộ nhớ:** Khi đổi `serverId`, hash code mới được tính toán trỏ sang bucket khác. `map.get(key)` trả về `null` ngay cả khi truyền đúng tham chiếu cũ! Entry cũ bị kẹt vĩnh viễn trong bucket cũ ("Ghost Entry"). |

## 4. Cơ chế cốt lõi cần ghi nhớ
1. **Thuật toán `HashMap.get(K)`:**
   - Bước 1: Tính hash code của key $h = 	ext{key.hashCode()}$.
   - Bước 2: Trộn hash `hash ^ (hash >>> 16)` và tính chỉ số bucket `index = (n - 1) & hash`.
   - Bước 3: Duyệt danh sách liên kết / cây Red-Black tại bucket đó. Tìm node có `p.hash == hash && (p.key == key || (key != null && key.equals(p.key)))`.
2. **Quy tắc vàng:**
   - Nếu $x.equals(y) == true$ thì bắt buộc $x.hashCode() == y.hashCode()$.
   - Nếu $x.hashCode() == y.hashCode()$ thì **chưa chắc** $x.equals(y)$ (xảy ra xung đột hash - Hash Collision).
   - Mọi đối tượng dùng làm Key cho `HashMap` hoặc phần tử trong `HashSet` **bắt buộc phải là BẤT BIẾN (Immutable)**.
